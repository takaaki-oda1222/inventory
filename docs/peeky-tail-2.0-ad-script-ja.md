## 5. 制作メモ

- 原版のキャプションは **1語ずつポップ表示される青ボックス**（カラオケ字幕）。日本語版は1語単位だと可読性が落ちるため、**文節単位（2〜5文字＋助詞）**での表示を推奨。
- セクション見出し（No.1〜No.5）の間はナレーションが**休止**しており、映像と見出しだけで見せる作り。この"間"がテンポを作っているので日本語版でも維持すること。
- 「Catisfaction Guarantee」は cat + satisfaction のダジャレ。和訳は音を残した「キャットスファクション保証」か、意味を取った「猫も満足保証」のどちらか。ロゴバッジをそのまま使う場合は英語表記のまま＋小さく和訳注記が無難。
- 動画内キャプションは 1:11 付近で一度だけ商品名を "Picky Tail" と誤表記している（他はすべて "Peeky Tail"）。日本語版では **Peeky Tail 2.0** に統一すること。
- 「30日間返金保証」「全額返金」を日本語広告で使う場合、景品表示法上の観点から**適用条件の明示**が必要。CTA画面に条件リンクを入れること。
